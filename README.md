# Portfolio
Interactive corporate portfolio website featuring immersive 3D–8D depth effects, Three.js WebGL visuals, and GSAP ScrollTrigger animations. Built with HTML5, CSS3, JavaScript, and Bootstrap 5, it delivers a formal, fully responsive showcase across mobile, tablet, and desktop.
Sonai Das — Personal Portfolio Website

A modern, responsive personal portfolio website designed to showcase professional experience, skills, services, projects, and personal branding through an immersive digital experience.

Built with a premium executive aesthetic, interactive 3D visuals, smooth animations, and responsive layouts.

🌐 Live Demo

Website: https://dassonai.netlify.app/

---

✨ Features

- Premium UI/UX — Modern executive-style design with a dark navy, gold, and slate color palette.
- Responsive Design — Optimized for desktops, tablets, and mobile devices.
- 3D Visual Effects — Interactive Three.js background with immersive particle and depth effects.
- Smooth Animations — GSAP-powered transitions, scroll reveals, and motion effects.
- Interactive Portfolio — Filterable project gallery with project detail modal.
- Professional Resume — Timeline-based education and experience sections.
- Services Showcase — Highlighting professional services and expertise.
- Skills Visualization — Animated skill progress indicators.
- Contact Section — Interactive contact form with email integration.
- Modern Navigation — Sticky navigation with mobile-friendly menu.
- Performance-Conscious — Responsive rendering, reduced-motion support, and mobile optimizations.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/sonai-das-portfolio.git

2. Navigate to the project directory

cd sonai-das-portfolio

3. Run the website

Open "index.html" in your browser.

For the best development experience, use the Live Server extension in Visual Studio Code.

🚀 Deployment

This project can be deployed using any static hosting provider:

- "Netlify" (https://www.netlify.com/)
- "GitHub Pages" (https://pages.github.com/)
- "Vercel" (https://vercel.com/)

Deploy with Netlify

1. Upload the project folder to GitHub.
2. Connect your GitHub repository to Netlify.
3. Configure the site as a static website.
4. Set the publish directory to the project root.
5. Deploy and share your portfolio.
